# Photographs

This directory contains the recovered stove photographs. Their provenance and
checksums are recorded in [`../../MANIFEST.md`](../../MANIFEST.md).

The ten JPEGs under
[`serial-5215-installed-controller/`](serial-5215-installed-controller/) were
supplied by the stove owner on 2026-08-21. They retain their received filenames
and bytes; no crop, rotation, metadata rewrite, or recompression was applied.
The set documents the installed component side, harness routing, auxiliary
output board, J3 connector area, and wider stove interior. A research-facing
index and evidence limits are in
[`../../../docs/hardware/installed-controller-photographs.md`](../../../docs/hardware/installed-controller-photographs.md).
